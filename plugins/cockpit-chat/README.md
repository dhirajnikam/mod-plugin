# cockpit-chat

Cockpit around the chat: the band above the prompt with progress and context, the spinner's words, tool calls as cards, and the line under the prompt.

Part of [Cockpit](../../README.md), split so you can install only the parts you want. It needs `cockpit-core`, which holds the state and the events, and draws into its pane. Install it at the prompt of a Claude Code session:

```
/plugin install cockpit-core --marketplace dhirajnikam/mod-plugin
/plugin install cockpit-chat --marketplace dhirajnikam/mod-plugin
```

Install the parts or the all-in-one `cockpit`, not both. This folder is generated by `scripts/split.py` from
`cockpit/`: change the code there.
