# cockpit-core

Cockpit's core: what every part reads. It follows the session (prompts, tool calls, turns, agents, the judges), keeps the state, registers the six experts and `/cockpit`, and draws the pane's header and tabs. Add the tabs you want as add-ons.

Part of [Cockpit](../../README.md), split so you can install only the parts you want. Install it at the prompt of a Claude Code session:

```
/plugin install cockpit-core --marketplace dhirajnikam/mod-plugin
```

Install the parts or the all-in-one `cockpit`, not both. This folder is generated by `scripts/split.py` from
`cockpit/`: change the code there.
